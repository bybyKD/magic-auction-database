# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please open an [issue](https://github.com/bybyKD/magic-chess-gogo-auction/issues) with the label `security`. Do **not** open a public issue — use GitHub's private vulnerability reporting feature if available.

You can expect:

- An acknowledgment within 48 hours
- A timeline for the fix within 5 business days
- Credit for the discovery if you wish
